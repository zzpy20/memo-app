Memos with notes, clips, files and tags, and search across all of them.
›

Works from anywhere, no Tailscale needed. The pages are public, but nothing opens without the passphrase — except a memo you've shared on purpose.

What it is
  • Personal memos. Each one has a rich-text note, quick clips pasted in as you go, files in folders, tags, links and a cover picture.
  • Search on the home page looks through titles, notes, clips, tags, file names and captions at once. Pinned memos stay at the top.
  • A memo can be shared as a read-only link, and revoked again. Deleted memos and files go to a Trash first.
  • Your iPhone can drop text, photos and files straight into a memo through iOS Shortcuts.
How it runs
  • All on Cloudflare — nothing on the Mac mini. There's no server to start or keep alive.
  • Two parts, published separately. The pages (Pages project memo-frontend) are rebuilt by GitHub each time a change to them is pushed. The Worker memo-worker checks the passphrase and does all the work; it is published by hand with sh deploy.sh.
  • Memos live in a D1 database (memo-db); notes, clips and files in an R2 bucket (memo-files).
  • Files are limited to 100 MB each. The passphrase is saved in each browser after the first sign-in.

Common tasks
  • Get something back: the 🗑 button on the home page for memos; the Trash inside a memo for its files.
  • Share a memo: ↗ Share on the memo's page makes a read-only link; revoke it there when done.
  • Take a copy out: on a memo's page, export the note as a standalone HTML file, export clips as Markdown, email the note to yourself, or download files as a zip.
  • Set up iOS Shortcuts: the ⌘ button on the home page opens the iOS Shortcuts Setup guide, with the addresses and IDs to paste in.
Where everything is
  • Project folder: ~/Projects/memo-app on the Mac — README.md explains everything in detail, including deployment and tests.
  • Code: github.com/zzpy20/memo-app (public — never put passwords in it).
  • On Cloudflare: the Pages project memo-frontend, the Worker memo-worker, the D1 database memo-db and the R2 bucket memo-files.
  • Secrets: the passphrase and the email settings live only as Worker secrets; the GitHub deploy uses CLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID stored as repo secrets.
